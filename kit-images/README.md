# kit-images

Photographs used as the header pictures of the themes' bootstrap kits (`wp/<theme>/kit/hero.jpg`). Each is a **free photo from
[Unsplash](https://unsplash.com)** under the [Unsplash License](https://unsplash.com/license) (Unsplash+ photos are not used),
resized to 1400 px. The photographer, their profile and the photo page are in [`credits.json`](credits.json), and every blog that
shows one prints the credit under it ("Photo by … on Unsplash").
